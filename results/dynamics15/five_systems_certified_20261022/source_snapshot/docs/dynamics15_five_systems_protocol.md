# 15节点、五类高阶动力学：实验预声明

日期2026-10-22。用户要求将节点数改为15并增加动力学类型，追加选择高阶SIS，因此采用Kuramoto、Lorenz、Lotka–Volterra、Stuart–Landau、SIS五类。此前R5、4节点试跑、30节点Pearson结果作为冻结历史证据保留。本轮只新增源码、配置、数据及报告。

## 方程、来源与改编边界

以下每个配置条目只求和一次，有向目标为i，j/k为不同源且都不同于i。没有对j/k另求一次排列，也没有隐含乘2。所有系统使用相同的45条有向成对边、15条三体边，每个目标3个成对输入、1个三体输入；三体两条目标—源成对面均存在。保持每目标入度时，15节点网络比30节点网络的候选边密度高。网络为固定合成结构。

1. **Kuramoto**：
   \(\dot\theta_i=\omega_i+\sum_j a_{ij}\sin(\theta_j-\theta_i)+\sum_{j<k}b_{ijk}\sin(\theta_j+\theta_k-2\theta_i)\)。沿用[THIS论文形式](https://arxiv.org/html/2402.00078v2)及项目既有实现。
2. **Lorenz**：内部方程为\(\dot x_i=10(y_i-x_i),\dot y_i=x_i(28-z_i)-y_i,\dot z_i=x_iy_i-8z_i/3\)，x方程另加\(\sum_j a_{ij}(x_j-x_i)+\sum_{j<k}b_{ijk}(x_jx_k^2-x_i^3)\)。同样沿用此前项目的论文式耦合；15个物理振子共45维。
3. **高阶Lotka–Volterra**：
   \(\dot x_i=x_i[r_i-x_i+\sum_j a_{ij}x_j+\sum_{j<k}b_{ijk}x_jx_k]\)。参考[Sidhom与Galla的模型式(2)–(3)](https://arxiv.org/html/2409.10990v1)。本轮采用稀疏、竞争性负系数，r_i在[.8,1.2]，不复现原文随机稠密群落相图。状态是正物种丰度，15维。
4. **高阶Stuart–Landau**：
   \(\dot x_i=(1-x_i^2-y_i^2)x_i-\omega y_i+\sum_j a_{ij}(y_j-x_i)+\sum_{j<k}b_{ijk}(x_jy_k^2-x_i^3)\)，
   \(\dot y_i=(1-x_i^2-y_i^2)y_i+\omega x_i+\sum_j a_{ij}(x_j-y_i)+\sum_{j<k}b_{ijk}(y_jx_k^2-y_i^3)\)，取\(\omega=1\)。耦合函数依据[Ghosh等式(2)](https://arxiv.org/html/2306.04614v1)，原文是全连接、带N归一化的系统。本轮改为相同稀疏有向底图，边权直接表示有效作用强度，非原文相变复现。每节点x/y两维，共30维。
5. **高阶SIS的确定性节点概率近似**：
   \(\dot p_i=-\mu p_i+(1-p_i)[\sum_j a_{ij}p_j+\sum_{j<k}b_{ijk}p_jp_k]\)，\(\mu=1\)。依据[Iacopini等的群组感染机制](https://www.nature.com/articles/s41467-019-10431-6)建立节点层面独立性闭合，用每节点概率而非全网单个感染率；本轮为加权有向超图变体。不是原文二值随机过程的逐事件模拟，也不将解析导数实验称为实测疫情数据。

## 共同的数据与库设置

固定拓扑seed2026102200，pair强度绝对值U[.2,.6]，triple强度绝对值U[.1,.3]。GLV取负，其余取正。各系统中心固定，Kuramoto/Lorenz/Stuart–Landau坐标为符号随机的[.3,.8]，GLV中心[.8,1.2]，SIS中心[.4,.6]；每坐标独立在中心±.3范围抽样。SIS保持(0,1)，GLV保持正值。非零中心用于THIS高阶偏导的结构读出，不以真值边调整中心。

每系统2个种子2026102201/2026102202，各1024训练、256验证、256测试独立初值；每初值只取t=0状态及解析导数，因此1536个样本均来自独立准备。没有时间积分、有限差分、吸引子预热或重复近邻时间点。它是局部瞬时向量场辨识实验，不能据此声称长期被动轨迹下也能恢复。相对于30节点轮，节点数、样本量、采样和筛选同时变更，因此不能将差异全部归因于节点数。

采用完整原生THIS、degree<=3库，不做Pearson、已知耦合通道或真实拓扑筛选。15维P=816；Stuart–Landau30维P=5456；Lorenz45维P=17296。每个方法看到相同数据、库、训练拟合的标准化和响应噪声。保留原生monomial indices；CSV为Float64的17位有效数字，并有Julia探针核对；大矩阵另存NPY，逐文件SHA可追溯。

0%/5%响应导数噪声；master seed2026102203。逐坐标标准差仅由训练干净导数估计，各分割和坐标RNG独立，各方法共享相同噪声。没有状态噪声、动力学过程噪声或随机感染噪声。

## 求解、选择及评价

M0D/M0sD保留原STLSQ的λ=.1、ρ=1、10次、常数惩罚和全局停止规则，使用已验证的primal/dual线性解代替显式逆，明确为数值变体。M1B/M2B调用既有普通/Adaptive BIC：K<=P、秩/条件数或残差方差不合要求时NA，不修改方差定义；零噪声多项式可能自然NA。M1vW/M3W为已测试的完整库工作集普通/Adaptive LASSO，工作集只是求解子问题，所有接受解都须对完整库通过KKT；不是删候选。

验证仍用12档alpha_fraction=[1,.3,.1,.03,.01,.003,.001,.0003,.0001,1e-5,1e-6,1e-8]，最多100000次迭代，tol1e-10，KKT1e-6，验证误差并列容差1e-12。工作集最多60轮、每轮最多增加64列，是预声明的计算设置，不根据测试真值调节。Adaptive为Ridgeρ1、gamma1、eps1e-6，外部标准化后不重复内部缩放。Python按节点独立进程、BLAS单线程，避免Python3.11线程警告捕获串线。

模型任一节点FAILED则整体FAILED；否则有NA则NA。可用节点单独保留，不能补零后评分。五系统×2seed×2noise×6方法=120个模型。所有模型状态及接受系数锁定后才计算真值与测试指标。

结构仍按原生THIS规则读出，再对多坐标物理节点取最大绝对系数，剔除物理自环和重复源。二体全候选210、三体全候选1365；F1固定abs(coef)>1e-8，AP使用全候选连续分值，失败/NA不当零。预测误差对照干净测试解析导数。仅2seed，不作显著性或总体优越性结论。必须另报告多项式精确表达/正弦Taylor近似误差、方法可用数、系数/边解码核对及旧结果哈希保护。
