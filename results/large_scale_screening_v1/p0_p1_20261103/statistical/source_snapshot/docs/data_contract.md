# THIS 数据契约（R0）

本契约依据官方 THIS commit `865efc43fe8ec21966659b482ca5756396974425` 的 `this-tools.jl`、`this.jl`。本轮只使用无 Pearson 筛选的 `get_θd → mySINDy → this`。数组方向、常数行、单项式数值已由 `scripts/smoke_r0.jl` 实测；日志为 `reports/r0_logs/julia_smoke.log`。

## 维度与回归方向

`N` 为节点数，`K` 为样本数，`dmax` 为最高单项式次数。完整多项式库包含所有次数从 0 到 dmax 的单项式（允许变量重复），所以 `P=binomial(N+dmax,dmax)`。

| 名称 | Julia 原始形状 | 含义 |
| --- | --- | --- |
| `X` | Float64 `[N,K]` | 每行一个节点，每列一个采样状态 |
| `Y` | Float64 `[N,K]` | 与 X 同节点、同样本的时间导数 |
| `θ` | Float64 `[P,K]` | 每行一个单项式，在所有样本上的取值 |
| `d` | Int64 `[P,dmax]` | θ 同行单项式的节点编号，0 为填充位 |
| `Ξ` / `coeff` | Float64 `[N,P]` | 第 i 行是目标节点 i 对所有特征的系数 |
| `X_design`（Python） | float64 `[K,P]` | `θ.T`，每行一个样本 |
| `y`（Python） | float64 `[K]` | Julia `Y[i,:]` 对应的单目标响应 |
| `beta`（Python） | float64 `[P]` | 同一目标系数，恢复后对应 `Ξ[i,:]` |

Julia 的联合回归为 `Y≈Ξ*θ`；Python 单目标为 `y≈X_design @ beta`。状态矩阵 X 与回归设计矩阵 X_design 含义不同。样本必须沿相同列序排列，系数列必须与 θ/d 的行顺序一致。

实测 N=3、K=5：dmax=2 得 θ=(10,5)、d=(10,2)；dmax=3 得 θ=(20,5)、d=(20,3)。不要仅凭 N 或次数猜测特征顺序。

## 索引与常数项

Julia 节点编号为 1…N，0 只表示填充，不是节点，也不能直接用作 Python 节点索引。Python 的行/列位置从 0 开始，但保存在 d 里的**节点编号仍保持 Julia 编码**。若未来需要索引 X 的 Python 节点行，只能对非零节点号显式减 1。

dmax=2 时的实际特征顺序如下。表内位置为 Julia 特征行号；Python 特征位置比它小 1。

| Julia 行号 | d 的原始行 | 单项式 |
| --- | --- | --- |
| 1 | `[0,0]` | `1` |
| 2 | `[0,1]` | `x₁` |
| 3 | `[1,1]` | `x₁²` |
| 4 | `[2,1]` | `x₂*x₁` |
| 5 | `[3,1]` | `x₃*x₁` |
| 6 | `[0,2]` | `x₂` |
| 7 | `[2,2]` | `x₂²` |
| 8 | `[3,2]` | `x₃*x₂` |
| 9 | `[0,3]` | `x₃` |
| 10 | `[3,3]` | `x₃²` |

θ 第一行为全 1，d 第一行为全 0；`Ξ[i,1]` 是常数偏置。禁止丢失 d、重排 θ、只按单项式名称重新生成一个“看起来相同”的特征库。原始 STLSQ 的岭项连同常数系数一起惩罚；未来 LASSO/Adaptive LASSO 的无惩罚截距策略须单独说明，并避免常数特征与额外截距重复。

## 从系数到交互

原始 `this` 仅保留所有非零源节点号互不重复的单项式，并排除目标节点出现在源集合内的情况；系数绝对值须大于 `1e-8`。因此针对目标 i，`x_j*x_k` 在 i、j、k 互异时可解码为三体作用 `i←{j,k}`；`x_j²` 仍保留在回归库中，但不能当作两个不同源节点的三体作用。

次数与交互阶数需分开：对通过上述规则的单项式，交互阶数为不同源节点数加上一个目标节点；并非直接等于次数。含目标的项或重复索引项可参与动力学拟合，但不通过原始高阶边解码。

`Ainf` 实际类型为 `Dict{Int64,Matrix{Float64}}`，按阶次 o 索引。`Ainf[o]` 有 `o+1` 列：目标节点、`o-1` 个源节点、系数；节点列在该浮点矩阵里是整数值。源节点在解码时排序，输出行遍历顺序不应被当作边的身份。

当前源码 `ooi` 虽然是参数，却未过滤返回阶次；`Ainf` 建立 1…dmax+1 的项。后续研究只评 2、3 阶，须明确选择 `Ainf[2]`、`Ainf[3]`。dmax=3 不代表只产生三体边。

## 导数与样本分割

- 解析导数：给定已知动力学 f，在状态 X 上计算 `Y=f(X)`。R1 首轮使用此方案。
- 估计导数：从离散状态观测作差分或其他微分估计，包含采样和微分误差；有观测噪声时误差可能放大。
- R0 smoke test 中 Julia 的 `Y=copy(X)` 仅用于验证函数接口，**不是动力学轨迹或物理导数数据**；Python 数据同样只是小型线性回归夹具。

数据分割按独立轨迹/初始条件执行；同一轨迹不得跨训练、验证、测试。训练集拟合归一化与初始化权重，验证集选择允许的超参数，测试集仅用于最后评价；禁止用测试真值或测试动力学误差选参数。R0 只规定契约，尚未实现任何数据集或分割器。

未来导出必须保存 Float64 至少 17 位有效数字、矩阵维度、索引基底、特征顺序标识与轨迹来源。CSV/TOML 跨语言桥接属于 R3，R0 未实现。
