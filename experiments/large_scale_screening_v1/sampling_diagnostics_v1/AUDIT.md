# 采样诊断 v1：执行前审计与固定协议（2026-11-03）

原 data.py 的 network/rhs 已支持任意 N 和稀疏耦合归一化；generate 仅实现 RK45，按整轨迹拆分。library.py 的候选映射固定为 P=6N−2+4K，decode 仅把目标外的交叉二次项读作三体。screeners.py 的五种统计评分只需训练状态和导数，Context 包含共同低阶投影。backend.py 是公共 M2 的薄封装，原 BIC 同时检查未加权和自适应加权库的条件数、数值秩、残差方差及 KKT。

最小修改位置：只在本子目录新增 sampling.py、diagnostics.py、runner.py、report.py、测试及说明；原 data/library/screeners/backend/neural、配置、checkpoint、历史结果全部只读。旧 trajectory 通过原 generate 调用，默认随机流保持一致。新 sampling_mode 默认 local_iid，可显式选择 trajectory。

固定网络/频率/随机非零中心/K2=.3/K3=.6，1024/256/256 样本、delta=.6。主对照统一以 net.center 展开；这是为满足同中心对照而显式固定的坐标协议，旧主接口仍按训练圆均值展开。B4 另检验中心的影响。local_iid 的 split 使用独立 SeedSequence 命名空间，group 是独立制备 ID，time=NaN；绝不接入神经窗口。

A：N15/30，0%/5%噪声，K16/32，五统计方法，先 seed_index=0,1，再扩展至总计30个不重复配对拓扑（包含前两个，单列 pilot，不能当32个）。仅当每个 N/noise/K 的至少95%目标拟合返回OK才扩量；否则保留拒绝并解释。指标使用原连续系数和1e-8阈值，无向结构按方向max；只要任一目标没有合法模型，全网指标NA。

B：先2个同A网络的配对种子，N30，5%噪声、K16、Pearson/FWL/SCC-OLS。B1 固定1024行和T=.5，4/8/16/32/64独立训练轨迹；验证/测试各256行，沿用相同每轨迹点数。B2 在4轨迹下比较T=.5/1/2/5。B3 固定独立局部样本的底层标准均匀抽样及单位高斯噪声，delta=.2/.4/.6/1/1.5；复用B1相同参数。避免把所有因素做笛卡尔积。必要时追加明确标记的激励边界检查，不能事后隐去失败条件。

行打乱控制：同一完整设计矩阵行置换，不重新筛选，核对奇异值谱的浮点相对误差，并对导数重新计算全局行序 lag-1；原按轨迹 lag-1另列，行序指标不解释为独立样本数。

B4：固定同一目标/候选（原4轨迹、FWL、K16的候选）对数据机制做嵌套0+1、0+1+2、0+1+2+3阶分析，目标0/1/2、两个种子；共同标准化规则、原始尺度及固定/训练圆均值/训练算术均值中心分别报告。SVD默认阈值=max(shape)*eps*smax，另列1e-4至1e-14相对阈值；谱熵有效秩、stable rank、最大项相关性、低阶空间对响应及非线性函数项解释率分别记录。原BIC判据只读。

截断误差独立计算完整动力学在固定中心的解析三阶 Taylor 多项式与干净rhs的差，不能与候选遗漏或回归误差混为一谈。记录所有有向三体交互的二阶交叉系数−K3/d3_i*sin(theta0_j+theta0_k−2theta0_i)，以及完整rhs的该交叉项有限差分核对。局部同步报告真实边相位锁定值、相位差与频率差，不能只用全局序参量。

每job保存完整数据、候选/分数/系数/库索引/谱、选参诊断、配置/源码哈希；恢复运行先核对协议和已完成文件哈希。不对BIC失败作回退、不运行神经网络。报告包含实际分布差异与测试网间变异，不从单一lag-1推断因果机制。所有受保护源码与历史交付清单在结束时重新核验。
