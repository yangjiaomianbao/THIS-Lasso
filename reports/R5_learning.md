# R5 扩展学习：30 seed、独立重复与配对区间

本节对应用户“执行下一阶段”后启动的 E1 完整扩展；后文 smoke 内容保留为历史解释，最终运行状态与结果以 [R5 报告](R5_report.md) 为准。

## 不同 seed 标签不等于独立初始条件

旧 R1 生成器使用 `config.seed + trajectory_id` 初始化每条轨迹。若相邻 trial 的 config.seed 只差 1，就会重复绝大多数轨迹初值；把它们直接当作独立初值重复进行 bootstrap 会使区间解释失真。首个批次在任何测试/结构评分前中止，保留 [中止记录](../results/r5/e1_full/aborted.toml)。

修正只在 R5 包装层进行：第 k 个 trial 使用 `trajectory_seed_base=1000000000+k*10000`，其 160 条轨迹使用 base+1…base+160。原始生成器、真实网络、模型参数、响应噪声与选参规则均保持不变。实际数组核对显示：中止批次 4800 条初值仅 189 个不同值，正式批次 4800 条均不同；证据见 [trajectory_independence.toml](../results/r5/e1_full_independent/trajectory_independence.toml)。

所有正式 30 组干净数据都是新的独立初值集合，不复用 pilot 干净数据。前两个 noise-seed 标签沿用探索阶段，产生相同标准高斯底样本，但其信号尺度和状态轨迹已不同。为透明起见，另报剔除这两个 noise-seed 标签后的 28 组敏感性结果，而不按成绩选择子集。

## 以 seed 为配对统计单位

每个独立 trial 包含四种方法和四档噪声，不能把这 16 个格子当作 16 次独立重复。同一 seed 的方法共用响应噪声，噪声水平间也共用底样本，因此配对信息应保留。

本次预先固定 10000 次 bootstrap，每次从 30 个 seed 索引中有放回抽 30 次；同一索引矩阵用于所有方法、噪声水平与指标。每个方法先按每 seed 得到 Precision/Recall/F1/MCC/AP，再统计这些 seed 指标的均值、样本标准差（ddof=1）及 bootstrap 均值的 2.5%/97.5% 分位数。它不是先合并所有边计数再算 F1。

配对 M2−M1 或 M2−M0 必须先在同一 seed 上相减，再对差值做同样重采样。不能把两个方法置信区间的上下界直接相减当成差值区间；共同的数据效应会改变差值的不确定性。单元测试用高度相关的共同 seed 效应、但恒为 1 的真实差值验证这一点。

这里的 95% 区间是逐点区间，不是整个噪声曲线同时覆盖的置信带，也没有多重比较校正。初值与噪声独立重复仍局限于同一物理拓扑，不能据此作跨网络泛化声明。

## NA、失败和分母必须随结果报告

0 噪声下 BIC 因满模型残差不足而 NA；这不是 F1=0，也不能通过假定一个噪声方差来填补。若某节点的选中解未收敛，整条 trial 标 FAILED，保留原因，不伪造系数。每个均值和配对区间都附带有效 seed 数、NA/FAILED 数。

缺失情况下只给有限可用样本的条件估计，明确可用性可能带来偏差；bootstrap 仍按完整 seed 簇抽样，某次抽样完全没有可用值时单独记录。正式图保留 NA 断点，不把缺项接到零。训练样本数、参数与迭代预算沿用 smoke，所有候选警告继续保留，不能因为选中解合格就假装整条路径达到相同精度。

## 可复核的输出

[正式结果目录](../results/r5/e1_full_independent/) 包含 480 条原始方法记录、逐 seed 配对差值、10000×30 的 bootstrap 索引、完整统计表、强度 Recall 和 PNG/PDF 图。所有模型先统一写选择锁，再计算测试误差和结构指标；评分不反馈给拟合。相关入口均为 R5 新脚本，前序求解器只读。

## E1 与 E2/E3 的差别

E1 固定干净 X、theta、d 和真实网络，只把回归响应替换成 `Y_noisy=Y_clean+eta`。这首先检验“特征准确、导数响应含噪”时的求解器行为。

E2 在模拟过程中施加扰动，状态轨迹和由其构建的特征都会改变；E3 对观测状态加噪，然后估计导数和特征，二者误差可能相关。三者不是同一数据模型。本次脚本只实现 E1，E2/E3 只列在 [后续方案](../docs/r5_followup_noise_plan.md)。

R4 只完成了两个种子的 A 阶段，30 种子 B 尚未执行。用户随后明确要求 R5，因此本次启动有限 E1 smoke，同时保留这个前置缺口；不能把它当作 R4 全量已验收或整个研究已经闭环。

## 噪声比是标准差比

对节点 i，只从干净训练列计算总体标准差：

`sigma_i = sqrt(mean_train((Y_clean_i-mean_train(Y_clean_i))²))`。

再令 `eta_i,k(r)=r*sigma_i*Z_i,k`，其中 Z 为预先固定的标准高斯样本。r=0、0.05、0.10、0.20 是**标准差比例**；对应的名义噪声方差比例是 r²，分别为 0、0.0025、0.01、0.04。r=0.20 不是注入 20% 的方差。

训练、验证、测试均各自注入噪声，但三个集合使用独立随机流；所有方法共享同一份噪声响应。有限样本的实际噪声标准差不会恰好等于目标值，metadata 同时保存目标值和实测值；不利用测试集统计量重新归一化噪声。若训练信号标准差为 0，则该节点在这种相对定义下的绝对噪声也为 0，测试已覆盖。

## 随机性如何复现和配对

[r5_noise.py](../scripts/r5_noise.py) 为每个节点/集合构造 PCG64 随机流，SeedSequence 的熵为 `[master_seed, clean_seed, split_code, node_Julia_ID]`。总噪声主种子为 2026101705，干净种子沿用 22261017、22261018，split_code 为训练/验证/测试的 1/2/3。每个 seed 的 24 条流、单位高斯矩阵、NumPy 版本和哈希均保存。

同一个 seed 的所有噪声水平共用 Z，再乘不同 r。这种共同随机数设计减少比较噪声水平时额外的随机变化；不同 seed 仍使用不同 Z。它也意味着不同噪声水平不是独立重复，未来区间估计应以完整 seed 为配对簇，不能把四档噪声当四个独立 seed。

## 数据方向、标准化和模型选择

原始 X/Y 为 8×480，theta 为 165×480，d 为 165×3。训练/验证/测试按完整轨迹拆分为 300/90/90 列，Python 训练设计为 300×165。d 的节点号仍是 Julia 的 1…8，0 是填充；列顺序不改变。

M0 保留原始 THIS 默认 λ=0.1、ρ=1、niter=10，使用干净原尺度特征与含噪训练 Y。M1/M2/M3 复用 R4 已锁定的公共特征标准化，均值/尺度只来自干净训练 X 的 Taylor 库；E1 不改变 X，因此四档噪声下公共 Z 完全相同。

M1 是普通 LASSO＋BIC；M2 是 Ridge 初值 Adaptive LASSO＋BIC；M3 是 Adaptive LASSO＋独立验证集选择。后两者 γ=1、ε=10^-6、Ridge ρ=1，权重只依含噪训练响应和训练特征计算。验证选择只用含噪验证响应，不窥视干净验证标签去替模型选参数，也不读测试误差决定 alpha。

标准化后得到 B，按 `C_j=B_j/s_j`、`C_constant=B_constant-sum(mu_j*C_j)` 还原，预测仍为 `C*theta`。最后一律在原始单位使用严格 `abs(C)>1e-8`，没有按噪声水平调评分阈值。

## 为什么 0 噪声时 BIC 会 NA

当 r=0，干净多项式精确包含在满库中，满模型残差不足以可靠估计噪声方差，沿用 R2 门槛明确拒绝 BIC；M1/M2 记 NA，不生成伪零系数。非零响应噪声下可能满足方差要求，但还要通过满秩、自由度、条件数、收敛/KKT 等检查，不能仅因 r>0 就强行认定 BIC 合法。

M1/M2 的配对是相同 BIC 策略下的权重比较；M2/M0 还改变预处理、常数项惩罚与选择策略，差异不能完全归于权重。M3 与 M2 的差异主要检查选择策略，但也必须面对数值误差和不同路径。

## 真强度分层不能用预测值

本次强度阈值在评分前固定：弱为真实绝对系数≤0.10，中为 (0.10,0.17]，强为 >0.17。只对真实交互分组，不将假阳性或预测得很小的边混进“真实弱交互”。

当前 R1 动力学每条交互恰好是一个带物理耦合系数的平方自由单项式，所以物理系数与对应原尺度 Taylor 系数相同；没有振子模型的三角展开或组合倍数。成对弱/中/强真边分别为 3/4/3 条，三体各 1 条。因此每个 seed 的弱三体 Recall 只能是 0 或 1，两个 seed 的描述均值非常粗，不能据此给出稳定的强度分层结论。

## 评价与噪声标签要分开

结构标签始终来自同一个干净网络，而不是含噪 Y 的非零值。THIS 解码仍排除重复源、含目标源的项；例如 x₅² 不变成两个不同源，偏置也不是成对或三体边。成对/三体候选分别为 56/168。

Precision、Recall、F1、MCC 和 AUPRC(AP) 都按同一候选全集计算。AP 使用系数还原后的绝对值连续评分，不先丢弃阈值以下的分数；无真实正例或负例时记 NA。固定结构判定与连续排序衡量不同方面：某方法可以用很小系数命中真弱边而保持 Recall，同时生成很多假边，导致 Precision/F1 降低。

响应预测误差分别记录相对 `Y_noisy` 和 `Y_clean` 的结果。前者包含不可预测的测试噪声，后者反映拟合漂移/干净动力学的误差；两者不应混用，更不能以较低 MSE 直接断定三体恢复更好。所有方法、seed 和噪声水平完成选择锁定后才评分，不根据测试反馈再次挑参数。

## smoke 能说明什么

14 项测试检查标准差定义、仅训练尺度、随机流复现、0 噪声、跨档比例、输入不变、强度边界、阶段限制，以及 NA/选中模型数值失败的显式保留。测试日志中模拟的 NA/FAILED 是预期的故障处理测试，不是实测 seed 被隐藏或剔除。

实际 smoke 原始计数、逐 seed 差值、强度 Recall 和数值警告见 [R5 报告](R5_report.md)。两种子均值仅是描述性结果，没有伪装成 30-seed 均值或 95% 区间。初值权重在噪声下可能把真弱项强烈惩罚，相关特征可替代真项，BIC 也可能选择对结构恢复不利的模型；这是待检验机制，不能只凭一张小表确认因果。

供自己思考的 3 个问题：

1. 为什么标准差噪声比 0.20 对应方差比 0.04，而不能说成 20% 方差？
2. 若方法预测很多小系数边，为什么弱交互 Recall 很高仍可能意味着结构恢复较差？
3. 同一 seed 共用四档噪声底样本时，未来 bootstrap 应按什么单位重采样？
