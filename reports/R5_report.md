# R5 E1：30 个独立初值 seed 的完整对照

更新日期：2026-10-17（Asia/Shanghai）。用户在 smoke 后要求“执行下一阶段”，本次按待执行的 **E1 30-seed 完整扩展**执行。**480 条记录已完成：420 OK、60 零噪声 BIC NA、0 FAILED，未剔除任何正式 seed；23 项测试通过。** E2/E3 仍只保留方案。

结论：**当前不支持自适应权重普遍优于普通 LASSO，或 Adaptive LASSO 全面更稳健。** M2 在 5% 噪声的平均三体 F1 略高于 M1，但配对区间跨 0；10% 也无明确 F1 优势；20% 的三体 F1 和 AP 均低于 M1。M2 在 5%/10% 优于默认 STLSQ，仍不能把算法、预处理和选择策略的全部差别归因于权重。M3 的非零噪声假阳性较多。

## 独立性修正及执行历史

首次批量方案沿用连续 trial seed，检查时发现旧生成器按 `config.seed+trajectory_id` 初始化轨迹，跨 trial 会复用初值。该批次在 **任何测试/结构评分前中止**，没有选择锁或正式统计；保留 [aborted.toml](../results/r5/e1_full/aborted.toml)、[原运行日志](../results/r5/logs/full_run.log) 和源码快照，整批不纳入最终结果。不是根据效果挑选 seed。

修正仅在 R5 包装器：trial k 的轨迹 seed 基数为 `1000000000+k*10000`，其 160 条轨迹使用 base+1…base+160。前序生成器保持只读，物理网络、耦合强度、K、噪声和全部模型参数不变。直接比较实际初值数组：中止批次 4800 条只有 189 个不同初值；正式批次 **4800 条全部不同，RNG seed 命名空间也不重叠**，见 [trajectory_independence.toml](../results/r5/e1_full_independent/trajectory_independence.toml)。单个旧 trial 内的轨迹分割仍有效；修正的是跨 trial 的初值重复设计。

正式结果唯一目录为 [e1_full_independent](../results/r5/e1_full_independent/)，配置为 [r5_e1_full_independent.toml](../configs/r5_e1_full_independent.toml)。30 个 trial 标签为 22261017–22261046，全部采用新的干净初值集合。前两个 noise-seed 标签沿用 pilot 高斯底样本；另报排除它们后的 28 组敏感性分析，没有按分数选择子集。历史 smoke 文件与报告原始字节保存在本目录 history/，前序数据和求解器未改。

## 预注册方法与数据

沿用固定 R1 网络：N=8、完整 dmax=3 库 P=165，真成对边 10、三体边 3。每 trial 训练/验证/测试独立轨迹为 100/30/30，每轨迹 3 点，样本为 300/90/90；X/Y_clean 为 8×480，theta 为 165×480，d 为 165×3，系数为 8×165。不同噪声水平保留同一 trial 的 X/theta/d/真值和分割。

E1 仅令 `Y_noisy=Y_clean+r*sigma_train*Z`，r 为 0、0.05、0.10、0.20 的**标准差比例**。sigma 只取每节点干净训练导数总体标准差（ddof=0）；训练、验证、测试使用不同 PCG64 流，各方法共用同一响应。同 trial 的四档共用高斯底样本，噪声主 seed=2026101705。逐节点尺度、随机流、eta、Y_noisy、输入哈希完整保存。没有执行过程或观测噪声。

| 方法 | 锁定策略 |
| --- | --- |
| M0 | 原始 THIS/STLSQ，原尺度，官方默认 λ=0.1、ρ=1、niter=10 |
| M1 | 普通 LASSO＋BIC，公共训练标准化、无惩罚偏置、R2 方差/秩检查 |
| M2 | Ridge 初值 Adaptive LASSO＋BIC，γ=1、ε=10^-6、Ridge ρ=1 |
| M3 | 同 M2 权重机制，独立轨迹含噪验证 MSE 选 12 点 alpha 网格 |

公共均值/尺度只用训练 theta；权重与 Ridge 只用含噪训练响应。所有系数还原原始 THIS 单位后，统一严格 `abs(C)>1e-8`，复用 R3 的重复源/目标排除规则，只评价 o=2/3，原生 o=1/4 输出仍保存。没有阈值扫描或事后调参。

[protocol.toml](../results/r5/e1_full_independent/protocol.toml) 在正式生成/拟合前锁定配置和源码。**所有 480 个模型选择于 22:37:06.310746+08:00 写入 [selection_locked.toml](../results/r5/e1_full_independent/selection_locked.toml)，之后才统一评分和计算测试误差。** 迭代预算仍为 max_iter=100000，未按测试成绩增删候选、种子或方法。

## 统计定义

先计算每 seed 的指标，再统计 30-seed 均值和样本标准差（ddof=1）。预先固定 bootstrap seed=2026101706、10000 次有放回重采样；同一 **seed 簇索引**用于所有方法/噪声水平，配对比较先同 seed 相减，再重采样差值。索引矩阵保存为 [bootstrap_seed_indices.csv](../results/r5/e1_full_independent/bootstrap_seed_indices.csv)。

区间为 **逐点 95% percentile 区间**，不是同时置信带，未作多重比较校正。NA/FAILED 不补 0，附带有效分母；存在缺失时仅解释有限可用样本的条件估计。0 噪声的 M1/M2 每组均为 30 NA，无法给出该点配对结果；所有非零噪声的方法均有 30 个有效 seed。

若 AP/Recall 出现 [1,1] 区间，仅表示本批观测及该 bootstrap 结果不变，不代表更广泛总体中必定完美。

AP 指 scikit-learn average_precision_score，不是梯形积分。连续边分数为同一合法目标/源集合对应原尺度系数绝对值的最大值；候选全集为成对 56、三体 168，零系数仍保留为零分数。Taylor 支持单独评价全部 1320 个位置，不与真实交互混同。

## 真实强度 Recall 与失败解释

分组固定为真实物理绝对耦合：弱≤0.10、中(0.10,0.17]、强>0.17，不按预测值分组。当前每个物理项与原尺度 Taylor 项一一对应；成对弱/中/强为 3/4/3 条，三体各 1。全部 [strength_recall.csv](../results/r5/e1_full_independent/strength_recall.csv) 和 [strength_summary_30.csv](../results/r5/e1_full_independent/strength_summary_30.csv) 保存 2880 条原始分层记录及区间。

20% 噪声下，弱三体 Recall：M0=0，M1=0.8000 [0.6667,0.9333]，M2=0.3667 [0.2000,0.5333]，M3=0.6000 [0.4333,0.7667]。M2 的中/强 Recall 为 0.7667/0.9333；因此退化主要集中在弱项，但不限于弱项。

一个低噪声失败例：seed 22261035、5%、M2，目标 3 的弱真边 3←{1,2}（Julia 特征 12，原系数 0.08）未恢复。其真实标准化系数约 0.02308，Ridge 初值约 −2.01×10^-6，导致权重约 331826，最终系数为 0。该 trial 三体 TP=2、FP=1、FN=1。所有同一真弱边的初值/权重/alpha/最终值见 [weak_edge_diagnostics.csv](../results/r5/e1_full_independent/weak_edge_diagnostics.csv)。这支持“初值接近零会过度惩罚真弱项”的可检验机制；相关特征、BIC 路径选择也可能共同作用，不声称单例证明因果。

M3 在 5%/10%/20% 平均三体 FP 为 7.20/8.87/9.47；其结构 Precision 和 F1 明显受损。预测验证误差的最小值并不直接约束结构误检。AP 较高而 F1 较低说明排序与固定阈值支持不同；未利用真值重新挑选有利阈值。

后续如研究不同 Ridge ρ/γ、初始化稳定性或稀疏性选参，应先建立新协议并独立验证，不能回改本次参数。本次是 E1、同一拓扑、K_train=300；不能推广到 E2/E3、不同网络或其他样本预算。R4 的完整 B 阶段仍未执行，不能声称所有研究阶段均已人工闭环。
