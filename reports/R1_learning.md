# R1 学习笔记：从 x₅*x₆ 到目标 7 的三体证据

本笔记前半部分保留原始失败案例。修订版在相同真实方程和特征顺序下，增加独立初始轨迹并缩短衰减观察窗，再用独立验证轨迹选择 λ、ρ。训练条件数降至约 21.28，选出 λ=0.03、ρ=0，成对和三体边均全部恢复。修订数据位于 data/r1/revision/，旧数据保留为对照。

## 先看方程，再看系数列

本次目标节点 7 的真实动力学为：

`dx₇/dt = -1.1*x₇ + 0.12*x₆ + 0.20*x₅*x₆`。

对每个保存的状态，生成器直接计算右侧作为 Y 的第 7 行。X、Y 均为 8×1640；训练只使用其中属于 24 条训练轨迹的 984 列。没有从时间差分估计 Y。

作者 `get_θd(X,3)` 生成 θ=165×1640 和 d=165×3。特征数 165 包含常数和全部 0–3 次单项式，不是 165 条三体边。

对源节点集合 {5,6}，查找 d 中剔除 0 后排序为 [5,6] 的那一行，得到 **Julia 特征行 138**。该行就是 x₅*x₆ 在所有采样点的数值；真值矩阵 `true_coefficients.csv` 的第 7 行、第 138 列为 0.20。

拟合后，系数 `coeff[7,138]` 决定这一项在估计方程中的强度。若该估计系数通过作者判零规则，源 5、6 互异且均不等于目标 7，就可解码为 `7←{5,6}`。它是一个有目标的三体作用，不把 5、6 的交换视为另一条边。

本次实际得到 `coeff[7,138]=0`，因此该真实三体边被漏检。补充诊断确认：其岭初始化为 0.0753152，小于 λ=0.1，第一次筛选即被删除；原始算法之后不再引入该列。**这是保留的失败案例**，不能因为真值为 0.20 就把预测改成存在。

## 平方项与三体作用的区别

`x₅²` 在 d 中有两个 5；它描述同一状态变量的平方，不是两个不同源节点。它仍可参与导数拟合，但作者的 this 解码会剔除重复源索引，因此不能作为目标 7 的两个源节点三体边。

针对目标 7，若特征是 `x₇*x₅`，源集合含有目标，也会被该解码规则排除。由此可见，“非零二次系数”与“真正解码出的三体边”不是同一统计量。

## 原始 STLSQ 在做什么

入口在 `scripts/r1_baseline.jl`；它通过 `r1_common.jl` 原样 include 官方 `upstream/THIS/this.jl`，没有修改作者代码。实际调用为：

`this(X_train,Y_train,[2,3],3,0.1,1.0,10)`。

作者内部先计算 `Ξ₀=Yθᵀ(θθᵀ+ρI)⁻¹`，再将绝对值小于 λ 的估计系数置零，对留下的特征继续岭重拟合。这里 λ=0.1、ρ=1、niter=10，全部使用作者默认值，没有用验证集或测试集标签选参数。

λ 作用于当前的**估计系数**，不是生成系统里的真值。因此即使真值 0.20 大于 λ，也不能保证该项被保留；相关特征和岭收缩可能影响初始化与后续迭代。原始 this 最后还用 1e-8 解码判零，这与 STLSQ 的 λ 是两个步骤。

训练 θ 数值满秩，但条件数约 6.89×10^8；这表示区分某些特征系数组合很困难。ρI 会稳定求逆，同时带来收缩。当前结果没有分离这些因素的因果贡献，不能仅凭漏检就把原因全部归给数值舍入或单一参数。

## 怎样解读本次指标

成对真值 10 条，恢复 5 条，FP=0、FN=5，所以 Precision=1、Recall=0.5、F1=2/3。三体真值 3 条，全部漏检；没有预测正例，Precision 按约定记 0、Recall=0、F1=0，MCC 因分母为零记 NaN。

测试集导数 MSE 约 0.000828，并不等价于恢复出正确三体结构：系统的自衰减和部分成对项可以解释很多导数变化，而少量三体项仍可能被完全遗漏。

从保存的 X/Y/θ/d 重放后，系数最大差为 0，解码边及计数一致。它证明计算与文件契约可以复查，并不证明恢复性能好。

## 自查问题

修订结果说明：原先“稳定且满秩”的要求还不够，数值条件和独立激励同样重要。更多独立初值帮助分开不同单项式；保持原始求解器，再由验证响应选择参数，可以避免依据结构真值直接调阈值。本次 ρ=0 的选择符合干净、良好数值条件数据的验证结果，不能直接移作未来含噪数据的固定结论。

2. 为什么本次 Precision=1 的成对结果仍有一半真实边未找回？
3. 为什么较小的导数预测误差不能代替三体 Recall/F1？
