# R4 学习笔记：公平对照与 dry run 的解释边界

## 本次问题与方法组

本次只执行 R4 的 A 阶段：两个预先固定的初始条件种子，N=8、训练 K=300。网络、真实系数、Taylor 库和解析导数定义沿用 R1。两个种子改变轨迹初值，不改变拓扑，因此是轨迹采样重复，不能解释成独立网络重复。

| 组 | 拟合坐标 | 选择策略 | 作用 |
| --- | --- | --- | --- |
| M0 | 原始 Taylor 单位 | 官方 STLSQ λ=0.1、ρ=1、niter=10 | 作者默认策略基线 |
| M0s | 公共训练标准化坐标 | 同一 STLSQ 数值参数 | 预处理控制，不更换算法 |
| M1 | 公共标准化坐标 | 普通 LASSO＋BIC | 与 M2 对照权重机制 |
| M2 | 公共标准化坐标 | Ridge 初值 Adaptive LASSO＋BIC | 自适应模型 |
| M3 | 公共标准化坐标 | Adaptive LASSO＋独立轨迹验证 | 检查选择策略 |
| M1v | 公共标准化坐标 | 普通 LASSO＋同策略验证 | 在 BIC 不可用时仍有明确命名的配对控制 |

M0s 的标准化与新方法相同，但原始 mySINDy 仍连常数项一起惩罚；两种 L1 方法的常数项不惩罚。保留这个差异才能保持原始算法，不应把 M0s 与 L1 的全部差异仅归因于稀疏优化器。

## 公共标准化和系数还原

原始 theta 为 `[165,480]`，其中训练/验证/测试列分别为 300/90/90；Python 训练设计为 `[300,165]`。节点数为 8，所以系数矩阵为 `[8,165]`。每条轨迹只有 t=0、0.05、0.10 三个采样点，整条轨迹只属于一个集合。

对非常数特征，仅用训练集计算 μ 和总体 RMS 尺度 s：

`Z_j=(theta_j-mu_j)/s_j`，第一行常数仍为 1。

若标准化坐标中系数为 B，则原始尺度系数为

`C[:,j]=B[:,j]/s_j`，`C[:,1]=B[:,1]-sum_j(mu_j*C[:,j])`。

因此 `C*theta=B*Z`，原始常数列吸收居中产生的偏置。必须先还原 C，才用统一的 10^-8 阈值评分；不能把标准化系数与原始系数混在同一张结构表里。

R2 的 `standardize=false` 在本次指“不再额外按列缩放”，因为 R4 已统一完成外部缩放；其训练集居中和无惩罚偏置策略仍保留。Ridge ρ=1、γ=1、ε=10^-6 均作用在这个公共标准化坐标中。自适应权重为 `w=(abs(B_init)+eps)^(-gamma)`；这与 R2 单独演示时“先转回原始单位再定义权重”的具体输入单位不同，本次已在配置中明确，不混作同一个预处理条件。

M0s 仍使用 λ=0.1，并不表示其原始物理单位的阈值与 M0 相同。特征缩放改变系数大小，等数值 λ、ρ 也改变有效正则几何；因此 M0s 此次输出零交互只说明“标准化＋保留官方数值参数”这一控制条件表现差，不能推断标准化本身普遍有害。

## 为什么 BIC 本次是 NA

M1 与 M2 复用已验收 R2 的方差/秩/条件数门槛。普通 BIC 包装器只读调用 `_prepare`、`_bic_variance`，再调用 `LassoLarsIC`；这使无权重和自适应方法的满模型噪声方差准则一致。M2 还检查其自适应缩放设计的数值条件。前序文件没有修改，私有函数版本由源码哈希锁定。

两个种子的训练设计均满秩 165，但无噪声多项式的满模型残差接近零，无法可靠估计 BIC 所需噪声方差。M1/M2 每个种子的八个节点均触发这一门槛。因此四条方法×种子记录保存为 NA，记录逐节点原因，不产生伪零系数或 F1=0，也不改名为验证方法。

额外 M1v 与 M3 都用同一验证集、同一 MSE 选择准则、同一 alpha_max 比例网格和同一同分规则。各方法的 alpha_max 根据自身加权设计计算，数值 alpha 不必相同；它们是同一种选参策略，不是固定同一个数值惩罚的实验。

## 两个层次的恢复不是一回事

Taylor 支持集评价全部 8×165=1320 个系数位置，真非零为 21，包含 8 个自衰减和 13 个交互。结构评价先按原始 THIS 规则排除重复源和含目标源的项，再分别评价：

- 成对：56 个有向候选，真边 10、负例 46。
- 三体：168 个目标有向/双源无序候选，真边 3、负例 165。

例如目标 i 的 `x_j*x_k` 只有在 i、j、k 互异时形成三体边；`x_j²` 不表示两个不同源。偏置或含目标项可以成为 Taylor 假阳性，却不会计为成对/三体假阳性。这次 M3 与 M1v 的结构 F1 都为 1，但 Taylor 假阳性分别为 4 和 9，正说明两个评价层次有差别。

结构判定固定为严格 `abs(C)>1e-8`。连续边分数是通过原始过滤规则、对应同一目标/源集合的原尺度系数绝对值最大值；不存在的项记 0。完整 Taylor 库中合法源集合通常只对应一列，这时就是该列绝对值。Python 的候选预测集合还逐项对照 Julia 的 Ainf，防止自行定义了另一种交互。

本次 AUPRC 使用 scikit-learn 的 **average precision（AP）**，不是梯形积分。只在正、负真值均存在时计算，空正例或全正例记 NA 并解释。M0s 所有边分数为零，但真值有正有负，AP 等于阳性占比：成对 10/56≈0.1786、三体 3/168≈0.01786。MCC 因没有预测正例而分母为 0，记 NaN/NA，不能伪写为 0。高度不平衡时只报 TN 很多或 accuracy 很高没有说服力。

## 三个研究问题

**“M2>M1 才能归因于权重吗？”**

M2 对 M1 是需要的直接控制，但一次胜出不是充分证据。需要同一数据、预处理、偏置策略、选择准则、评分规则和配对种子，并检查数值收敛与跨重复的不确定性。BIC 本身沿不同的加权路径选模型，结果还包含权重与路径/选择的共同作用。本次 M1/M2 都为 NA，无法给这个比较下结论；M3 对 M1v 在两个种子的结构 F1/AP 差均为 0，也没有显示结构恢复优势。

**“为什么仅比较 M2 与 M0 不够？”**

它们同时改变了算法、初始化、尺度、常数惩罚和模型选择，看到差异无法分离原因。M0s 帮助检查预处理条件，M1 对 M2 才比较相同 BIC 策略下的权重机制，M2 对 M3 检查选择策略。在本次 BIC 不可用时，另列 M1v 对 M3；不能偷换原来的 M1/M2 名称。

**“回归误差降低是否一定表示三体边恢复提高？”**

不一定。降低误差可能来自更准确的自衰减、偏置，或用重复源/含目标的多项式近似轨迹；这些都未必增加合法三体边。相关特征之间也可能替代，预测近似相同却支持集不同。本次 M3 测试 MSE 约 2.9×10^-14，M1v 约 8.0×10^-13，三体 F1/AP 却都为 1，误差差异没有转化为更多正确三体边。

## dry run 暴露的问题

训练原始/标准化条件数约 2.9×10^3 / 1.5×10^3，高于 R1 的大训练集；两个种子均满秩，没有以条件数不理想为由换种子。普通 LASSO 验证组在最小 alpha 的 14 个未选中候选上达到 100000 次迭代上限；全部警告、误差和迭代次数保留。选中候选均无收敛警告并通过 KKT，M3 没有候选警告。

这些未收敛候选意味着当前路径的所有候选并非同等数值精度，扩大实验前应审阅数值预算和预注册策略。本次不在看到结果后修改网格、删候选或增加噪声来让 BIC 可用。两种子的计数、NA 和警告是管线检查证据，不是 30 种子性能分布，更不是含噪实验结论。
