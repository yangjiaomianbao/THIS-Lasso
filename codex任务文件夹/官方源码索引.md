# 两篇论文的 GitHub 官方源码索引

本文件通过 GitHub 仓库 README 与默认分支文件列表核对。**仓库代码可能变化，实验前须使用 `git rev-parse HEAD` 固定 commit。**

## THIS / Delabays 等人

仓库：https://github.com/TaylorBasedHypergraphInference/THIS

- README：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/README.md
- `this.jl`：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/this.jl
  - `mySINDy`：岭初始化、迭代阈值、重拟合；R0/R1 学习及 R3 替换点。
  - `this`：特征调用与高阶交互解码；R1/R3 必学。
  - `this_filter`：Pearson 预筛选版，**本轮不用**。
- `this-tools.jl`：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/this-tools.jl
  - `get_θd`：生成单项式 θ 和索引 d。
  - `keep_correlated`：Pearson 筛选，**本轮不用**。
- `this-parallel.jl`：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/this-parallel.jl （暂不修改）
- `eeg-run.jl`：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/eeg-run.jl （EEG 应用入口，基线前期无需全量运行）
- `eeg-tools.jl`：https://github.com/TaylorBasedHypergraphInference/THIS/blob/main/eeg-tools.jl （EEG 数据预处理工具）

README 标注环境 Julia 1.9，包：`Combinatorics`, `DelimitedFiles`, `EDF`, `FFTW`, `LinearAlgebra`, `Statistics`。代码许可证 GPL-3.0。

**注意**：官方 `this(X,Y,ooi,dmax,...)` 的 `ooi` 用于声明关注阶次，函数内部的 `Ainf` 可能仍有其它阶次；评价时应显式过滤指定的 2/3 阶。原始 `this` 解码只考虑不同的源节点索引，并且要排除目标节点作为源节点的情况。

## 克隆命令（VS Code 终端）

```bash
mkdir -p upstream

git clone https://github.com/TaylorBasedHypergraphInference/THIS.git upstream/THIS

git clone https://github.com/Weiwei-Su112/Adaptive-LASSO-for-higher-order-oscillatory-systems.git upstream/Su-AdaptiveLASSO

git -C upstream/THIS rev-parse HEAD
git -C upstream/Su-AdaptiveLASSO rev-parse HEAD
```

GitHub 网页也可直接下载 ZIP：打开仓库 → Code → Download ZIP。优先保留原作者文件，修改版写到独立 `src/`。

## 对照阅读推荐顺序

1. THIS `README.md` → `get_θd` → `mySINDy` → `this`；先理解固定 Taylor 库怎样解码成超边。
2. Su `README.md` → `GeneralInteraction.py` 中 Adaptive LASSO 的初始权重、特征缩放、LARS/BIC、系数还原；不要搬运正弦函数库。
3. 阅读 `R2_adaptive_lasso.md` 的目标函数和 `R3_integration.md` 的维度映射，再开展复现。
