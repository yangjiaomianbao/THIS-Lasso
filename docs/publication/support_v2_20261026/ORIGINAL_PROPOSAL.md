# THIS + LASSO：五类动力学全规模支持集与结构误检诊断实验 V2

## 1. 研究目标

本次实验旨在检验 LASSO 类方法在未知动力学高阶网络结构推断中，是否存在候选 Taylor 函数项保留过多的问题，以及该问题是否能够通过现有正则化和选参策略解决。

**本轮不引入新的正交投影筛选算法，不以提高最终 F1 为唯一目标。**

重点回答三个研究问题：

**Q1：普通 LASSO 和 Adaptive LASSO 最终保留多少非零 Taylor 函数系数？**

统计完整函数支持集、支持集大小及其在不同动力学、噪声条件下的变化。

**Q2：这些非零函数项是否对应大量虚假的普通边与三体超边？**

分析函数数量、预测结构数量、FP、FN、F1、AP 等指标之间的关系。

**Q3：能否通过调整正则化强度和现有 BIC、Validation 选参策略解决？**

分析正则化路径及结构解码敏感性，判断现有方法是否已经能够控制候选规模。

附加研究问题 Q4：如果 Q1–Q3 表明合理选参后仍存在大量难以消除的虚假交互，再对这些交互进行相关性、数值秩与条件正交投影诊断，为后续二次筛选算法提供依据。

## 4. 第一项核心实验：非零函数系数数量

这是本轮最重要的新增统计。

对于所有状态为 OK 的模型，读取最终拟合的系数矩阵：

\[
\hat B\in\mathbb R^{D\times P}
\]

计算：

\[
K_{\mathrm{coef}}(\tau)
=
\sum_{i=1}^{D}\sum_{j=1}^{P}
\mathbf 1(|\hat B_{ij}|>\tau)
\]

至少统计：

- 精确非零系数数量。
- 原实验绝对阈值 \(10^{-8}\) 下的非零系数数量。
- 按相对数值容差统计的有效系数数量。
- 各目标节点方程的非零系数数量。
- 不重复的非零 Taylor 基函数数量。
- 总支持率和按方程统计的支持率。
- 所选 alpha 及选参分数。

同时按照物理源节点集合分类函数项，区分常数、自身项、二体相关、三体相关及其他高阶项。

不得把 Taylor 多项式次数直接等同于物理交互阶次。多维动力学必须正确处理状态坐标与物理节点的映射。

为了判断“过多”，还应引入两个参考：

**参考 A：** 解析 Taylor 系数的有效支持集大小。作为合成实验诊断，不参与拟合和模型选择。对于非多项式动力学，要明确其依赖截断阶数和展开点。

**参考 B：** 不同 alpha 下的支持集变化，以判断现有选参是否保留了过多弱函数项。

输出文件：

`01_coefficient_support_seed.csv`

`02_coefficient_support_summary.csv`

第一张表保存种子级记录，第二张表汇总不同动力学、噪声、方法的均值、标准差、分位数和置信区间。

## 5. 第二项核心实验：函数数量与结构误检的关系

对同一模型分别统计：

\[
K_{\mathrm{coef}},\quad
K_{\mathrm{pair}},\quad
K_{\mathrm{triple}}
\]

其中：

- \(K_{\mathrm{coef}}\)：非零 Taylor 函数系数总数。
- \(K_{\mathrm{pair}}\)：预测二体交互数量。
- \(K_{\mathrm{triple}}\)：预测三体交互数量。

进一步统计：

- TP、FP、FN、TN。
- Precision、Recall。
- F1、AP、MCC。
- 测试 NMSE。
- 真实与虚假交互的评分分布。
- 有效运行数及 NA 原因。

重点分析函数数量与结构误检的关系。

需要区分以下情况：

A. 非零系数很多，预测虚假交互也很多。

B. 非零系数很多，但最终结构恢复准确。

C. 非零系数较少，但仍有大量虚假结构。

D. 非零系数很少，但真实交互大量漏检。

对于每类情况，在五种动力学中寻找对应实例。

不要仅凭相关性将函数数量过多认定为 FP 的因果原因。若需要因果证据，应通过固定数据与其他配置、改变单一筛选机制进行受控比较。

输出：

`03_support_structure_relation.csv`

## 6. 第三项核心实验：正则化与选参充分性分析

对普通 LASSO 和 Adaptive LASSO 分别检查正则化路径。

优先复用已有 alpha 网格和求解结果。

对于每个 alpha，保存：

- 非零 Taylor 系数数量。
- 预测二体数量。
- 预测三体数量。
- 验证集 MSE。
- BIC（适用时）。
- 训练误差。
- F1、AP、Precision、Recall、NMSE。
- 求解状态、收敛信息及 KKT 检查结果。

比较：

1. 当前 BIC 选参。
2. 当前最小验证 MSE 选参。
3. 更保守的验证集选参，例如条件允许时的 1-SE。
4. 固定 LASSO 系数，仅改变最终结构解码阈值。
5. 改变 alpha，但保持相同结构解码阈值。

其中第 4、5 项必须独立分析，区分回归函数支持集选择和最终结构解码选择。

BIC 不适用时保留 NA，不得使用其他方法悄悄替代原 BIC。

允许单独增加替代信息准则作为探索实验，但必须用新的方法名称标识，不纳入原有六方法的直接比较。

实验最终判断：

- 更强正则化是否减少 FP？
- 这种减少是否伴随 Recall 明显下降？
- 是否存在较简单的模型，其验证误差与当前模型近似，但结构误检显著减少？
- 当前 LASSO val 是否经常选到正则化路径中过于复杂的一端？
- Adaptive LASSO 的加权惩罚是否真正减少了非零系数？

输出：

`04_alpha_path.csv`

`05_parameter_selection_diagnostics.csv`

`06_decoder_threshold_diagnostics.csv`

## 7. 附加机制诊断：正交投影是否必要

本阶段暂不提出新的筛选算法。

只有在 Q1–Q3 显示仍存在值得解释的多余候选交互后，才进一步检查候选组的冗余性。

对已选物理交互组：

\[
R_g=(I-P_{-g})\Theta_g
\]

报告条件投影残差、组间相关性、数值秩、奇异值及独立验证集上的组删除重拟合贡献。

投影空间应限于适当的基础函数与竞争交互组，避免在 \(P\gg M\) 时使用全部函数列导致投影残差人为接近零。

对于大规模 Lorenz 函数库，应采用局部竞争集和数值稳定的 QR/SVD，不构建巨大的稠密投影矩阵。

合成真实标签仅用于事后分析真实组与虚假组的冗余特征是否可区分。

**本阶段不根据真实标签选择投影阈值，也不将低投影残差直接解释为虚假结构。**

输出：

`07_redundancy_diagnostics.csv`

## 8. 统计比较方法

### 8.1 同一种动力学内部比较

每个动力学、噪声条件下，以数据种子为配对单位，比较：

- Adaptive BIC − LASSO BIC。
- Adaptive val − LASSO val。

至少统计 F1、AP、Precision、Recall、NMSE 和非零系数数量的配对差值。

对 BIC 的 NA，仅使用双方都有效的配对种子，并单独报告共同有效样本数及失效比例。

输出：

- 配对均值差。
- 配对差分布。
- 95% 置信区间。
- 正负差值所占比例。
- 有效配对数。

置信区间可采用种子级配对 bootstrap，固定 bootstrap 随机种子及重采样次数。

### 8.2 跨动力学比较

五种动力学分别报告，不直接混合原始非零系数数量。

因为不同动力学的状态维度和候选函数库规模不同，应该同时报告归一化支持率。

跨动力学总结应描述共同趋势与反例，而不是只报告一个总均值。

### 8.3 多网络统计

采用网络种子和数据种子的层次化统计。

分别分析：

- 网络间变异。
- 相同网络下的数据与噪声变异。
- 方法比较的网络级配对差。

可采用网络级聚类 bootstrap 或层次 bootstrap，避免把同一网络下的多个数据种子当作独立网络样本。

## 10. 执行顺序与算力控制

本次实验规模较大，特别是 Lorenz 的完整候选库。

采用以下顺序：

**第一步：已有结果核验与支持集统计。**

不重新生成数据，不重复拟合已有有效系数。

**第二步：扩展到全部 30 个数据种子、三档噪声。**

完成六种方法的必要拟合及结构指标统计。

**第三步：分析完整正则化路径。**

优先复用已有求解路径，增量完成缺失部分。

**第四步：执行有限范围的候选组冗余诊断。**

不进行完整高维全组两两投影。

**第五步：扩展多网络种子。**

检验前四步发现的规律能否跨网络结构成立。

每步需要保存可恢复的运行状态。高维模型应记录实际时间、内存和失败原因，不得为节省计算量而直接删除真实候选函数。

如果某一阶段的计算资源不足，应保留已完成结果，报告缺失组合及其原因，不得选择性省略表现不利的方法。

## 11. 最终判断标准

`REPORT.md` 最终必须分别回答：

**Q1：是否存在非零函数系数过多？**

给出跨动力学、噪声和种子的统计证据，同时指出哪些条件下该问题不明显。

**Q2：多余函数项是否与虚假超边增加有关？**

区分函数级支持集膨胀和结构级误检，给出相关性及必要的受控诊断。

**Q3：通过现有正则化和选参机制是否足以改善？**

区分通过 alpha 调整能解决的问题，以及通过结构解码调整能解决的问题。

**Q4：正交投影二次筛选是否具有进一步研究的必要性？**

仅根据实验结果作出以下之一的判断：

- 当前问题主要来自选参或结构阈值，暂时不需要新增投影模块。
- 合理选参后仍存在显著冗余，支持研究结构级投影二次筛选。
- 真实与虚假交互存在明显不可辨识性，简单投影删除可能不可靠。

不得预设正交投影一定有效，也不能把候选数量降低本身当成算法成功。

最终交付重点是**识别真实问题及其适用条件**，为下一阶段的算法创新提供可信依据。
