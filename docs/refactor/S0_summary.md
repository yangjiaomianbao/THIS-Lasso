## 最重要的依赖与重构边界

`r5_batch.py` / worker /分析/审计仍导入 `r4_experiment.py`、`r4_methods.py`、`r4_metrics.py`；Julia准备和解码仍依赖 `r1_common.jl` 与 `src/this_adapter.jl`，后者include只读THIS原程序。因此“阶段旧”不构成冗余证据。

实际流程为固定模型/独立轨迹 → 原生get_θd → 训练标准化 → 普通LASSO或Ridge权重Adaptive（BIC/独立验证）或原始STLSQ → 原尺度还原 → 先写选择锁 → 原生兼容解码/结构指标 → 配对seed bootstrap与绘图。仅响应导数加噪，Taylor/真值/轨迹不因噪声改变。

M0s/M1v是R4中的预处理/选参对照，应保留；R4 B及R5 E2/E3均未执行。原生STLSQ惩罚常量、LASSO无惩罚偏置，不能以统一接口改变。R3桥接与R5直接fit_node是两条需分别保护的调用路径。

现有audit和独立性检查脚本存在写回正式目录的副作用；尤其旧 `r5_audit.py` 可能把阶段级manifest写回“仅smoke”。后续验收必须先隔离写入。历史路径、协议源码哈希和受保护文档导致物理归档/代码提取都须先有S1冻结。
