# S2–S4：算法公平性与分层随机设计

## 共同输入与自由截距

原生THIS构造完整三阶库。只用训练集计算非恒定特征的均值和中心化RMS，验证/测试套用同一组统计量。偏置列维持全1，均值记0、尺度记1。

三个求解器共同接收`Z_train`和`Z_validation`，在内部取`Z[:,1:]`作为惩罚特征；不再标准化。由于这些列已中心化，自由截距为训练响应均值。STLSQ在`y-y.mean()`上执行原Ridge+硬阈值机制，截距不进入Ridge矩阵或剪枝。

完整标准化系数为`[b,beta]`。用已有`restore_coefficients`恢复：非恒定项为`beta/scales`；偏置减去恢复后非恒定系数与训练特征均值的内积。训练空间与原Taylor坐标空间的预测逐方程核验一致。这里还原特征标准化，不撤销动力学展开中心。

原LASSO/Adaptive实现及LARS数值加速器完全不变。Adaptive的训练Ridge初估采用rho=1，变换系数`a=abs(initial)+1e-6`，最终L1权重`w=1/a`，gamma=1；调用旧加权目标及全库KKT检查。求解器接口没有测试数据、真实边或候选索引参数。

## 统一验证选择

每个目标方程独立选择参数，三种方法都使用同一验证响应的MSE。

比例网格为`[1, .3, .1, .03, .01, .003, .001, .0003, .0001, 1e-5, 1e-6, 1e-8]`。

- 普通LASSO：训练`alpha_max`乘比例；所有权重为1。
- Adaptive：训练加权`alpha_max`乘相同比例；权重来自训练Ridge。
- STLSQ：训练标准化Ridge系数绝对值最大值乘比例；rho=1，沿用原计数停止机制与10轮上限。

所有方法在`1e-12 * mean((y_validation-y_train.mean())²)`的数值误差容差内取降序参数路径的首项。这是确定性的较大相对惩罚优先规则，不等价于保证选择最少非零系数。验证响应能量仅用于并列容差，不能影响训练标准化或Adaptive初始权重。

`selection_details.csv`保留全部实际参数、12档验证MSE、非零数和选择标志。边界选择另行统计，后续即使发现端点常被选中，也不能用已观察的结构F1改写当前锁定网格。

**统一验证集MSE选参，是为了公平比较三种回归方法，不保证能得到结构恢复F1最优的模型。**

## 随机流

种子主命名空间为2026102301，采用NumPy SeedSequence派生，所有实际种子已写入`configs/fair_comparison_v2/seed_manifest.csv`，完整配置也含30条重复记录。

| 随机来源 | 派生命名空间 | 作用 |
| --- | --- | --- |
| network_seed | master, 1, network_id | 标识10个独立网络实现 |
| topology_seed | master, 2, network_seed, 0 | 每目标随机选3个不同外部源，再从中选2个作为三体源 |
| weight_seed | master, 2, network_seed, 1 | 独立采样45个成对和15个三体强度 |
| data_seed | master, 3, network_id, sample_id | 每网络3次独立准备，30个数据种子全部不同 |
| noise_seed | master, 4, network_seed, data_seed | 与网络/采样标识绑定、独立于上述流的噪声命名空间 |

Julia沿用原数据生成公式：每个样本的MersenneTwister种子为`data_seed*1000000 + system_code*100000 + sample_id`。五系统的system_code固定为1–5，即使只生成Kuramoto/SIS，SIS仍为5，不因子集改变。当前每数据集1536样本，小于系统命名空间宽度100000；全部30×5×1536个种子名无碰撞。

噪声对每个系统、split和状态方程再派生：`[noise_seed, network_seed, data_seed, system_code, split_code, variable_id]`。三个方法读取同一组白噪声及响应；0%和5%共享同一个底层标准正态数组。缩放仍为`eta * std(clean_Y_train, ddof=0)`。

独立性核验包括命名空间无重复、真实状态样本无重复、相同种子精确重放、修改权重种子不改变拓扑、跨系统共用结构/绝对强度，以及分割互斥。它是伪随机流分离与可重放证据，不把“种子不同”本身宣称为对任意统计依赖的数学证明。

## 网络与统计单位

10个网络均满足15节点、45个有向成对边、15个有向目标/无序双源三体边；每目标3条成对输入和1条三体输入，两条目标—源成对面都存在。禁止自交互与重复边。GLV使用负耦合，其他系统使用同一绝对权重的正耦合。

所有系统的固有参数、展开中心和采样箱宽与V1保持一致。网络间既改变拓扑也改变权重，不称为纯拓扑效应。30个数据重复嵌套在10个网络中；候选边/节点不是统计重复单位。

主表先逐完整网络/数据实例计算F1、AP、MCC、Jaccard，再求有效实例均值与ddof=1标准差。配对差异严格匹配同一实例和共享输入指纹。置信区间重采样独立网络的有效配对均值，采用网络等权；同时提供全部有效配对的pooled均值，说明缺失不均衡时两者可能不同。

bootstrap预先锁定种子2026102302和2000次重采样；不足2个有效网络时不生成区间。正式实验也只有10个网络，区间可能不稳定。网络间均值SD与网络内RMS SD是描述性波动，不作去混杂的方差分量估计。
