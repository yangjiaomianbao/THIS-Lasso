# Kuramoto / Lorenz 首次动力学扩展试验

预声明日期2026-10-21（Asia/Shanghai），授权来自用户“通过THIS文件，试一下Kuramoto方法和洛伦兹方法”。本次只新增配置、生成器、运行入口、测试与独立输出，不修改上游及既有R0–R5证据。

固定版本的THIS仓库提供推断核心和EEG示例，没有两种系统的生成脚本。本试验依据[THIS论文的合成数据模型](https://arxiv.org/html/2402.00078v2)自行实现方程并复用原生THIS，不宣称逐图复现论文。

## 固定模型与采样

Kuramoto：导数为自然频率，加配置的二体sin(θj−θi)项与三体sin(θj+θk−2θi)项。4节点、5条有向二体边、2条有向三体边。所有配置边各计一次，不隐含源排列翻倍。

Lorenz：3个振子，每个三个状态，σ=10、ρ=28、β=8/3。只在x方程加入二体a(xj−xi)和三体a(xj*xk²−xi³)。3条有向二体边、1条有向三体边；三体j/k在方程中有不同角色，结构真值将源集合视为无序。

完整方程参数、拓扑、非零展开中心和采样范围在[配置](../configs/dynamics_pilot.toml)。局部坐标u=x−center；所有方法使用同一完整三阶Taylor库。Kuramoto有35列，Lorenz有220列。系数的“原尺度”指未标准化的局部u坐标，不冒充未平移x坐标的全局系数。

每系统2个seed；每seed128/32/32条独立训练/验证/测试短轨迹，每条3个样本，共576个状态、384个训练点。每条显式独立RNG命名空间；RK4、解析导数、不做相位取模。该设计检验局部结构，不检验长时混沌预测。

响应噪声比例0%、5%；每节点σ由干净训练导数总体标准差确定，训练/验证/测试使用分离噪声流，比例之间共享单位噪声，所有方法共享同一响应。选参用带相应噪声的验证导数；最终预测误差相对干净测试导数。没有过程噪声、状态观测噪声或数值微分。

## 方法与选择

M0原生THIS/STLSQ，M0s标准化STLSQ；M1普通LASSO+BIC，M2Adaptive+BIC，M1v普通LASSO+验证集，M3Adaptive+验证集。STLSQ参数和LASSO数值预算沿用既有R4值。训练集计算特征均值/RMS、Ridge初值/权重；独立验证轨迹选允许的参数；所有方法状态/系数哈希锁定后才计算测试误差及真值分数。

不使用测试或结构真值选择alpha、阈值、中心、噪声或拓扑。不为改善结果重抽seed。BIC不适用保留NA，收敛失败保留FAILED及每节点理由，不能当作零分或自动切换选参方式。

## 结构评价及已知限制

保持原生THIS的变量级重复源/目标排除和严格1e−8阈值。Lorenz使用上游one2dim按三个变量聚合，跨变量最大绝对系数作为物理边得分，再排除物理自边和重复物理源；Python独立计算同一规则，与Julia输出精确核对。

预声明的全部候选有向物理二体/三体边计算AP及固定阈值precision/recall/F1/MCC。高阶作用会贡献低阶系数，因此两系统所选拓扑包含三体作用对应目标←源的二体边；这是一种明确的有利拓扑条件，不能据此宣称对无二体边界的任意超图同样有效。

零噪声Lorenz可被三阶库精确表达，BIC方差门槛可能不满足；Kuramoto仍有Taylor截断误差。所有seed和可用数保留；2 seed仅用于工程试跑，不提供显著性检验、置信区间或正式优劣结论。
