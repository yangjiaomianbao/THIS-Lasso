## 必须保留的共用依赖

`scripts/dynamics30.py` 中的数据读取、Taylor特征处理、噪声和评价辅助函数仍被15节点流程使用；`scripts/dynamics30_native_decode.jl` 是15节点结构解码核验的共用入口。因此保留这两个文件及15节点实验自己的源码快照。`dynamics30.py` 的旧30节点命令行运行所需专用配置/准备脚本已删除，不再作为可用的30节点实验入口。

## 依赖维护
