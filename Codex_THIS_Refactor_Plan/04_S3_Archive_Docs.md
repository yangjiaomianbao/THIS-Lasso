# S3｜报告去重与可追溯归档（需 S2 通过后单独执行）

**只整理自有报告/说明与过时实验展示，不修改核心代码/正式数据；原则上只移动和制作索引，不删除。**

要求：
1. 建立 `docs/README.md` 作为文档导航，并指定一个当前有效的 R5 主报告（例如原 `R5_report.md` 的稳定路径），不可偷偷改写结论。
2. 将 R0–R4 学习笔记、过时迭代讨论稿、重复图、历史 smoke、aborted 中止批次日志等分类到 `archive/` 或保持原位但建立索引。**aborted 数据为随机独立性问题的审计证据，不得简单认定为垃圾。**
3. 维护 `archive/INDEX.md`：原路径、现路径、时间、来源、是否被正式报告引用、归档原因、如何恢复。
4. 对正式报告和正式结果中的相对路径进行引用检查。若重写链接，只修改链接不改研究结论或统计数值。
5. R4 的 `M0s`、`M1v` 及未完成 R4 B、E2/E3 计划文档要保留，明确标记“未运行/待授权”，不能当作无用文档删掉。
6. 中止批次、数值警告、负面结果、零噪声 BIC NA 与全部 30 seeds 的证据必须可找到。

交付：更新的 `docs/README.md`、`archive/INDEX.md`、文件移动映射和 broken link 检测报告。

禁止删除、禁止自动删除未引用文档；“当前无引用”不等于“无研究价值”。阶段结束停止，等用户批准 S4。
