# Codex 项目重构计划｜THIS Taylor + LASSO / Adaptive LASSO

## 任务目标
在**保留 THIS 原始 Taylor 特征构造与高阶交互结构解码**的前提下，整理现有 R0–R5 工程；合并重复的基础组件、清理报告和临时文件，同时完整保留数据、正式指标、实验配置、种子、协议与重现实验所需证据。**这是一项重构和文件治理任务，不是算法升级任务。**

### 当前事实与不可越界之处
- R5 E1 完成 30 个独立初值、多噪声配对实验；`420 OK + 60 个零噪声 BIC NA + 0 FAILED`；不抹去 NA。
- M0=原始 THIS/STLSQ 默认；M1=普通 LASSO+BIC；M2=Ridge 初始化 Adaptive LASSO+BIC；M3=同 Adaptive 权重+独立验证 MSE。
- 当前尚不能认定 LASSO 求解器本身全面优于 STLSQ，也不能认定 Adaptive 全面优于普通 LASSO。20% 响应噪声 M2 三体 F1 低于 M1；弱交互漏检是待研究事实，不能借重构“修好”。
- R4 的 `M0s`、`M1v` 对照，以及未完成的 R4 B、R5 E2/E3 都具有后续用途，**不得当作无用文件删除**。
- 用户尚未提供工作目录树与所有源码；Codex 必须依据**实际仓库**确定路径、引用和依赖，不要猜测文件存在。

## 不可修改（硬约束）
1. 两篇原论文的原始源代码及其原始仓库/子模块维持只读，保留来源和版本信息；严禁把修改写入上游目录。
2. 不改 Taylor `get_θd` 特征公式、顺序、`d` 索引、`dmax`、任何结构解码规则；不改标准化公式、截距处理、Ridge 初始化、权重、L1/LARS 求解、BIC、alpha 路径、STLSQ、阈值、种子及真值。
3. 不改变正式 R5 数据/结果目录内容，不覆盖 `selection_locked.toml`、`protocol.toml`、`artifact_manifest.toml`、`trajectory_independence.toml`、`trials.csv`、`summary_30.csv`、`paired_summary_30.csv`、`weak_edge_diagnostics.csv`、正式日志、原始图表及失败/警告记录。
4. 不根据已知结构真值或既有测试 F1 调参。重构期间不引入 Pearson 改进、H/SC 分类、投影预筛选、采样范围选择或 E2/E3 新实现。
5. **默认禁止删除**。`git clean -fdx`、`rm -rf`、批量通配删除、强制覆盖、历史改写均禁止。旧报告、smoke、aborted 记录优先归档；安全删除须提供逐项清单并获得用户额外明确批准。
6. 仅执行本次用户批准的阶段。每一阶段完成后**停止**，列出改动、可验证输出、通过/失败测试和下一阶段待批准项；不能连跑下一阶段。

## 建议使用方式
- 先将整个计划包放到本地仓库以外或工作树受控目录；**只把本次要执行的一个阶段**粘贴给 Codex。
- 第一轮先运行 `01_S0_Inventory.md`；**不要直接从合并/删除阶段开始**。
- 若某文件或必要路径不存在，写入缺失说明并停止；不得自行补造基线或借用旧数据。
- 源码迁移允许提出目标路径，但需以实际 import/include 与跨语言调用方式决定，**避免为了好看强制拆 Julia 文件**。
